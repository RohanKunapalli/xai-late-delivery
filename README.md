# Explainable AI for Predicting Late Delivery in E-Commerce Shipping

Code for the paper by Rohan Kunapalli, IEEE BigData 2026 High School Symposium (paper SP19216).

## Run it
Open `XAI_Late_Delivery_Full_Study.ipynb` in Google Colab or Jupyter and click Run All.
It reproduces every table and figure in the paper (about 1-2 minutes).

## Data
`Train.csv` is the public Kaggle dataset "E-Commerce Shipping Data" by Prachi Gopalani:
https://www.kaggle.com/datasets/prachi13/customer-analytics
